# Task Management App

---

## Description

A Python-based application designed to help users manage their tasks efficiently. This app allows users to create, view, update, and delete tasks, supporting personal productivity and organization.

---

## Features

- Create new tasks with title and description
- View a list of all tasks
- Update existing tasks
- Delete tasks
- Mark tasks as complete or incomplete
- Simple and intuitive user interface

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/<your-org>/ADLC-aava-practice.git
   ```
2. Navigate to the project directory:
   ```bash
   cd ADLC-aava-practice
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the application:
   ```bash
   python app.py
   ```
