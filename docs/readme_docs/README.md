Small E-commerce Website
---

Description

A small e-commerce website that allows users to browse products, add items to their cart, and complete purchases online. This project demonstrates a basic online shopping platform suitable for small businesses or as a learning template.

Features

- User registration and authentication
- Product browsing and search
- Shopping cart management
- Secure checkout process
- Order history for users
- Admin dashboard for product and order management

Installation

```bash
pip install -r requirements.txt
```
